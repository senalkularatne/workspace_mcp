# MCP Servers to Consider

Track potential MCP servers here before adding them to a project. “Selected” means we want to evaluate or use it; it does not imply credentials or configuration are in place.


## Considerations

### Version Control

#### GitHub

- Use: Repositories, issues, pull requests, and code review.
- Status: Selected for evaluation.
- Source: [GitHub MCP Server](https://github.com/github/github-mcp-server)

### Design

#### Figma

- Use: Design files, components, and design context.
- Status: Selected for evaluation.
- Source: [Figma MCP Server docs](https://developers.figma.com/docs/figma-mcp-server/)

### Browsers

#### Playwright

- Use: Browser automation, page inspection, and UI testing.
- Status: Candidate.
- Source: [Playwright MCP](https://github.com/microsoft/playwright-mcp)
